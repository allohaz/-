# Пульт для ПК

Телефон на Android управляет компьютером с Windows. Два способа связи:

* **Bluetooth** — телефон притворяется клавиатурой и мышью. На компьютере ничего ставить не нужно (подходит для вуза).
* **Wi-Fi** — программа `PultServer.exe` на компьютере + приложение. Работает только внутри локальной сети.

Папки: `android/` (Kotlin, без XML и библиотек), `server/` (Python), `.github/workflows/build.yml` (сборка в GitHub Actions).

## Протокол Wi-Fi (версия 2)

TCP, порт по умолчанию 8765. Каждое сообщение — одна строка JSON, заканчивается `\n`.

1. Телефон: `{"v":2,"t":"hello","code":"123456"}`
2. Компьютер: `{"ok":true,"v":2,"name":"MY-PC"}` или `{"ok":false,"err":"BAD_CODE"}`

Коды ошибок: `BAD_CODE` (неверный код), `LOCKED` (5 неудачных попыток — подожди минуту), `NOT_LOCAL` (не домашняя сеть и не Tailscale), `BAD_VERSION`, `BAD_MESSAGE`.

После этого команды (все с `"v":2`):

| Что | Сообщение |
|---|---|
| Курсор | `{"t":"move","dx":5,"dy":-3}` |
| Курсор в точку экрана | `{"t":"abs","x":0.5,"y":0.2}` (от 0 до 1) |
| Кнопка мыши | `{"t":"btn","b":1,"down":true}` (1 левая, 2 правая) |
| Двойной / тройной клик | `{"t":"click","b":1,"n":2}` (`n` от 1 до 3) |
| Прокрутка | `{"t":"scroll","n":2}` (больше нуля — вверх) |
| Клавиша | `{"t":"key","k":"ctrl+c"}` (одна `win` — просто клавиша Win) |
| Текст | `{"t":"text","s":"привет"}` |
| Медиа | `{"t":"media","k":"playpause"}` (`next`, `prev`, `volup`, `voldown`, `mute`) |
| Система | `{"t":"system","a":"lock"}` (`lock`, `sleep`, `shutdown`, `restart`, `cancel`) |
| Моя кнопка | `{"t":"custom","id":0}` |
| Отправить на ПК | `{"t":"share","s":"https://..."}` (ссылка откроется, текст попадёт в буфер) |
| Буфер в ПК / из ПК | `{"t":"clip_set","s":"..."}` / `{"t":"clip_get"}` |
| Подтверждение кадра | `{"t":"ack","s":12}` (телефон шлёт на каждый полученный кадр) |
| Разбудить погасший экран | `{"t":"wake"}` (сервер делает настоящий толчок мыши и возвращает курсор на место) |
| Экран ПК | `{"t":"screen","on":true,"q":2,"w":2400}` (качество 1–3, `w` — ширина экрана телефона в пикселях, необязательно) |
| Игра: клавиша зажать/отпустить | `{"t":"keyd","k":"w","down":true}` (буквы, цифры, `space shift ctrl alt tab esc enter`, стрелки, `f1`–`f12`) |
| Игра: камера (относительная мышь) | `{"t":"gmove","dx":12,"dy":-4}` |
| Игра: кнопка мыши | `{"t":"gbtn","b":1,"down":true}` |

Ответы компьютера после входа:

* кадр экрана — строка-заголовок `{"t":"frame","n":123456,"k":0,"s":12,"r":3,"cx":0.4,"cy":0.7}`, сразу за ней (после `\n`) ровно `n` байт JPEG, без base64. `s` — номер кадра (его телефон подтверждает сообщением `ack`), `r` — ступень качества 0..4: компьютер сам понижает её, если кадры доходят с задержкой, и повышает, когда канал свободен. `k`: 0 — быстрый кадр (пока картинка движется, до 60 в секунду), 1 — чёткий (приходит, когда картинка замерла на 0,2 с). Если экран не меняется, кадры не шлются;
* `{"t":"cur","cx":0.4,"cy":0.7}` — картинка та же, сдвинулся только курсор (0..1);
* `{"t":"clip","s":"..."}`, `{"t":"shared","s":"..."}`, при ошибке команды `{"ok":false,"err":"BAD_MESSAGE"}`.

Ещё ответ на `hello` содержит список «моих кнопок»: `"buttons":[{"id":0,"name":"Блокнот"}]`.

Клавиши: стрелки `left right up down`, `enter esc tab space backspace delete home end pgup pgdn`, `f1`–`f12`, буквы, цифры; модификаторы `ctrl shift alt win` через `+`.

Игровые команды идут через `SendInput` со сканкодами, как у настоящей клавиатуры и мыши. Если связь оборвалась, сервер сам отпускает все зажатые клавиши и кнопки. Игра, запущенная от имени администратора, не принимает ввод от обычной программы: запускай `PultServer.exe` тоже от администратора.

Безопасность: сервер принимает только адреса частных сетей и Tailscale (`100.64.0.0/10`), проверяет код при каждом подключении, не более 300 сообщений в секунду, выполняет только команды из списка выше.

## Настройки сервера

Файл `settings.json` рядом с `PultServer.exe` (открывается из меню значка: «Настройки и мои кнопки»):

* `port` и `code` — порт и код доступа (код можно сменить из меню значка);
* `buttons` — «мои кнопки». Пример: `{"name": "Папка", "open": "C:\\Users\\Me\\Documents"}`, `{"name": "Блокнот", "run": "notepad"}`. Команды из `run` выполняются только отсюда, телефон прислать их не может.

После правки файла просто переподключись с телефона, перезапускать программу не нужно.

Отправка на ПК: в любом приложении на телефоне «Поделиться» → «Пульт для ПК».

## Экран на весь экран (Wi-Fi)

Вкладка «Экран» → «На весь экран». Телефон поворачивается горизонтально, картинка занимает всё место.

* Панель сверху (сворачивается ▲, возвращается ☰, листается вбок): **Касание/Тачпад**, **Двойной**, **Тройной**, **Правый**, **Выделить / тянуть**, Все, Копир., Вырез., Встав., Отмена, Del, Esc, ⌨, Зум, качество, ✕.
* «Двойной», «Тройной», «Правый», «Выделить / тянуть» действуют на **следующее** касание, потом всё возвращается к обычному клику. Подсвеченная кнопка значит «включено». Двойной клик выделяет слово, тройной — строку; «Выделить / тянуть» зажимает левую кнопку, пока палец на экране (выделение текста, перенос окон и файлов).
* Обычное касание — левый клик, два пальца — прокрутка, два пальца коротким касанием — правый клик, удержание — перетаскивание.
* ⌨ — полупрозрачная клавиатура поверх картинки (RU/EN, «123» — знаки, Esc, Tab, стрелки; Ctrl/Alt/Win нажимаются перед буквой). ⇅ на клавиатуре — картинка либо под ней, либо над ней.
* Зум ×1,5 / ×2 / ×3: картинка увеличивается и едет за курсором.
* Счётчик справа в панели показывает реальные кадры в секунду (в покое «покой»).

Качество: «Лёгкое» (до 30 к/с), «Плавное» (до 60 к/с), «Чёткое» (до 45 к/с, больше разрешение). Фактическая частота зависит от Wi-Fi и компьютера.

Проверка без телефона: `python test_client.py 127.0.0.1 8765 КОД screen`.

## Доступ из другой сети (Tailscale)

1. Поставь Tailscale на ПК (в настройках включи «Run unattended») и на телефон, войди одним аккаунтом. В админ-панели у ПК выбери «Disable key expiry».
2. В меню значка `PultServer` появится строка `Tailscale: 100.x.y.z:8765`. Её и вводи в приложении (Wi-Fi), код тот же. Tailscale на телефоне должен быть включён.
3. При первом запуске `PultServer.exe` разреши доступ и для частных, и для общественных сетей (или добавь правило брандмауэра для порта 8765).
4. Порт на роутере не пробрасывай.
5. Для работы после перезагрузки: автовход в Windows и «Запускать вместе с Windows» в меню значка.

## Боковая зона-тачпад

В режиме «На весь экран» кнопка «Тачпад: справа / слева / выкл» отодвигает картинку и ставит рядом полосу, где палец двигает курсор, кликает (касание), прокручивает (два пальца), перетаскивает (удержание) и работает с инструментами «Двойной», «Правый», «Выделить / тянуть». Картинка при этом не закрыта пальцем. Режим «Касание» (курсор прыгает под палец на картинке) включается кнопкой «Касание/Тачпад», по умолчанию включён «Тачпад».

## Плавность и диагностика

Пока картинка движется, сервер держит кадров столько, сколько позволяют канал и процессор: если канал узкий, кадр становится меньше (ступени 1–6), если не успевает кодирование, тоже. В покое приходит один чёткий кадр. Раз в 3 секунды передачи сервер пишет в `server.log` (рядом с `PultServer.exe`) строку вида:

    экран: 38 кадр/с, ступень 4 из 5 (запас), кадр 42 КБ, кодирование 11 мс, захват 14 мс, доставляется 12.6 Мбит/с, задержка 180 мс

Как читать: «захват» и «кодирование» близки к 1000/fps мс или выше, значит упирается компьютер; «доставляется» близко к размеру кадра × кадр/с, значит упирается канал. В скобках причина последнего переключения ступени («канал», «процессор», «запас»).

## Игровой режим (Wi-Fi и Tailscale)

Вкладка «Игра» → «Запустить игровой режим». По Wi-Fi позади кнопок показывается картинка игры с ПК (профиль «плавность важнее чёткости»: 60 к/с как цель, без чётких кадров и курсора). По Bluetooth картинки нет.

* Стик слева (WASD), камера справа. Кнопка «Огонь» ведёт и камеру: держишь огонь и тянешь палец. Несколько пальцев одновременно.
* «Меню»: камера превращается в курсор, касание это клик (для меню игры).
* ⚙: чувствительность камеры по осям, прозрачность кнопок, картинка игры (вкл/выкл, качество), «Настроить кнопки», «Сбросить кнопки».
* Настройка кнопок: перетащи кнопку, размер ползунком, клавиша из списка (в том числе ЛКМ/ПКМ), «Камера пальцем», «Удалить», «+ Кнопка». Раскладка запоминается.

Захват экрана: сервер использует DXGI (`dxcam`), если он есть в сборке, иначе обычный (`mss`). Обычный захват часто даёт чёрный кадр в играх на весь экран. В игре ставь «Полный экран в окне» (borderless), `PultServer.exe` запускай от администратора, если игра запущена от администратора. Уровень «Макс. fps» в режиме «На весь экран» делает кадры меньше, но чаще.

## Видео H.264 (чёткая картинка и 50–60 к/с)

Если в сборке сервера есть `av` (PyAV с FFmpeg), экран идёт видеопотоком, а не отдельными JPEG: передаются только изменения, поэтому картинка чётче и плавнее при той же полосе. Кодирует видеокарта (NVENC у Nvidia, AMF у AMD, QSV у Intel), если подходит драйвер, иначе процессор (x264). Телефон раскодирует аппаратно (`MediaCodec`). Если видео не запустилось, всё возвращается к JPEG.

Протокол: телефон шлёт `{"t":"screen","on":true,"q":3,"w":2400,"codec":"h264"}`. Компьютер отвечает `{"t":"vmode","codec":"h264","enc":"h264_amf","w":1920,"h":1080}` (или `"codec":"jpeg"`), потом кадры: строка `{"t":"vid","n":..,"k":1,"s":12,"w":1920,"h":1080,"r":4,"p":80,"cx":..,"cy":..}` и сразу `n` байт H.264 (Annex B; `k`=1 ключевой кадр с SPS/PPS; `p` задержка, мс). На каждый кадр телефон шлёт `ack`. Если поток сбился, телефон шлёт `{"t":"idr"}`, и компьютер присылает ключевой кадр.

Битрейт подстраивается под канал (лестница 1,2–16 Мбит/с): сервер сравнивает, сколько он отправил и сколько реально доставлено, и при нехватке канала пересоздаёт кодировщик с меньшим лимитом (на миг приходит ключевой кадр). Разрешение зависит от уровня: «Лёгкое» 960 px, «Плавное» 1280, «Чёткое» 1920, «Макс. fps» 1280 с лимитом поменьше. Кнопка «Видео» в панели включает и выключает видео. В `server.log` каждые 3 секунды пишется строка «видео: ... кадр/с, ... Мбит/с, кодировщик, задержка».

## Игровой режим: раскладки

Сверху по центру переключатель «Шутер», «GTA пешком», «GTA авто». У каждой раскладки свои кнопки (их можно двигать, менять размер и клавиши), свои настройки стика и авто-бега. Кнопки «залипания» (нажал: клавиша удерживается, нажал ещё раз: отпустилась) полезны для газа и бега. «Авто-бег у края стика» сам зажимает Shift, когда стик отклонён вперёд до упора. При прицеливании (правая кнопка мыши) камера замедляется (множитель в ⚙). Клавиши GTA V в раскладках стандартные для ПК, проверь их в настройках игры и при необходимости поменяй в «Настроить кнопки».

## Максимальная чёткость и плавность

* Уровень «Оригинал»: родной размер экрана, лимит до 40 Мбит/с, самый низкий CRF (чётче). Для экрана 1920×1080 и телефона 1080×2400 в горизонтали картинка ложится на экран 1:1 без размытия при масштабировании.
* Видео слегка мылит цветной текст (цвет в видео хранится с половинной чёткостью). Поэтому, когда картинка замерла на ~0,7 с, поверх видео приходит один JPEG без потерь по цвету, родного размера. Когда картинка снова движется, он убирается.
* Ровный ритм кадров: сервер просит у Windows таймер с шагом 1 мс (по умолчанию ~15 мс) и ведёт кадры по расписанию.
* Кодировщик x264 сам подбирает пресет: не успевает, берёт быстрее; есть запас, берёт качественнее.
